# Windows 수업 시험판 수정본

[수정 ZIP 받기](./algorithm-grid-windows-pilot.zip?raw=true) · [실행·교체 안내](./START-HERE.md)

2026-10-09 한국 시간 수정본입니다. 수업 정지 입력 차단, 학생 함께 이동, 활동 다시 닫기, 실행 허용 표시, 상단 생각 시간을 고쳤습니다. 표현 활동은 순서도 → 명령어로 쓰기 → 확인·제출로 정리했고, 최초 지도·명령 고치기·참고 명령 동시 보기를 반영했습니다.

기존 사용자는 새 ZIP을 **새 폴더**에 전부 풀고, 기존 **START 창만 Ctrl+C**로 종료한 뒤 새 폴더의 **START.cmd**를 실행하세요. **TUNNEL 창·브라우저·예전 폴더는 유지**하고 기존 HTTPS 주소를 새로고침합니다. 같은 Windows 사용자와 같은 DB·포트 설정을 사용하면 기존 답안을 이어 씁니다. 필요한 DB 갱신 전 자동 백업합니다.

클라우드에서 단위·브라우저 검사, 린트·타입 검사·빌드, 독립 학생 3명의 저장·서버 재시작 복구와 이전 DB 업그레이드 백업을 확인했습니다. ZIP 안 verification.json에 실제 검사 범위를 기록했습니다. 이전 시험판은 사용자 PC에서 실행했지만 **이 수정판의 Windows 실행과 30명·90분 시험은 아직 확인 전**입니다.

Node.js 24.19.0과 cloudflared 2026.10.0의 공식 체크섬을 확인했습니다. 첫 실행은 무료 운영 패키지를 내려받으며 추가 유료 API·서버를 도입하지 않습니다. 실제 DB·환경 파일·인증 정보·Linux node_modules는 포함하지 않습니다. 전달 전용 브랜치로 main과 앱 CI 배포를 변경하지 않습니다.
