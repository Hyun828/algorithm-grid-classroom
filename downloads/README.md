# Windows 접속 시험 다운로드

[실행 ZIP 받기](./algorithm-grid-windows-pilot.zip?raw=true) · [실행 안내](./START-HERE.md)

ZIP 전체를 압축 해제한 뒤 START.cmd를 실행하고, 서버 준비 후 TUNNEL.cmd를 실행하세요. 터널 창의 HTTPS 주소로 접속합니다. 첫 실행은 무료 운영 패키지를 다운로드합니다. Windows 실제 실행은 사용자 PC에서 확인 전입니다. 가상 학생 3명으로 먼저 시험하세요.

Node.js 24.19.0과 cloudflared 2026.10.0은 공식 체크섬을 확인했습니다. 앱의 기존 production 빌드를 포함하며 Linux node_modules, 실제 DB, 환경 파일, 인증 정보는 없습니다. 기본 브랜치나 운영 앱 배포를 변경하지 않는 전달 전용 브랜치입니다.
