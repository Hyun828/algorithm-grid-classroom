# Windows PC 교실

[새 실행 ZIP 받기](./algorithm-grid-windows-pilot.zip?raw=true) · [실행·교체 안내](./START-HERE.md)

**90분 성능 조건은 미통과입니다.** 이 ZIP은 기능 확인·리허설용 프로토타입입니다. 실제 수업 운영 완료판으로 표시하지 않습니다.

- 단위 검사 **1,244개**, 브라우저 검사 **158개**, 린트·타입 검사·빌드와 실행 묶음 업그레이드 검사는 통과했습니다.
- 합성 학생 **30명·교사 API 1개, 실제 90분** 동안 **197,655개 요청** 중 계획 밖 요청 시간초과 **225건**이 발생했습니다. 원인은 미확정입니다.
- 최종 저장 **18,076건**, 30명의 최종 제출과 DB 무결성은 누락·중복 없이 일치했습니다. 마지막 대기열은 0개, 정상 교사 반영 p95는 **1.78초**였습니다.
- 실제 Windows·30대 브라우저·집 인터넷·학교망은 미검증입니다. 미니 PC에서는 START 준비 후 **RUN-LOAD-TEST.cmd**로 같은 API 부하 검사를 실행할 수 있습니다. 이전 실패 기록을 포함한 상세 결과는 ZIP의 `verification.json`에 있습니다.

PC 화면으로 정리하고 수업 코드 입력을 없앴습니다. 교사는 개인 교사용 링크, 학생은 학생용 링크에서 번호나 별칭으로 참여합니다. 교사 화면의 **다음 학급으로 초기화**는 이전 풀이를 지우고 같은 학생 링크로 새 학급을 시작합니다. G마켓 산스·큰 글자·단계별 학습 화면을 유지합니다.

기존 사용자는 ZIP을 **새 폴더**에 전부 풀고 기존 START를 종료한 뒤 새 **START.cmd**를 실행하세요. 같은 Windows 사용자·DB·포트 설정을 사용하면 기존 자료를 보존하며 필요한 DB 갱신 전에 백업합니다. 이번 역할 링크 버전으로 처음 바꿀 때는 기존 TUNNEL도 종료하고 새 폴더의 **TUNNEL.cmd**를 실행하세요. 자동으로 열리는 안내 파일에서 교사용 버튼을 열고 학생용 링크만 공유합니다. 새 터널 주소에는 기존 학생 브라우저 권한이 이전되지 않으므로, 기존 답안이 필요한 학급은 교사 현황에서 먼저 확인하세요.

Node.js 24.19.0과 cloudflared 2026.10.0의 공식 체크섬을 확인했습니다. 처음 실행할 때 무료 운영 패키지를 내려받으며 추가 유료 API·호스팅·DB를 사용하지 않습니다. 실제 학생 DB·교사 비밀 키·환경 파일·인증 쿠키·Linux node_modules는 ZIP에 포함하지 않았습니다. 공개 수업 생성은 기본 차단되어 있습니다.

이 브랜치는 ZIP·체크섬·안내만 전달합니다. main과 앱 CI 배포는 변경하지 않습니다. 실제 미니 PC·학교망 리허설 및 시범 수업은 아직 검증하지 않았습니다.
