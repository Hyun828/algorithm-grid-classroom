# 알고리즘 탐험 교실 — 수업 시연 수정본

[Windows ZIP 내려받기](./algorithm-grid-windows-pilot.zip) · [시작 안내](./START-HERE.md) · [SHA256](./algorithm-grid-windows-pilot.zip.sha256)

- 학생: 오른쪽 고정 학습 단계, 빨강·노랑·파랑·초록 명령, 제출 뒤 완료됨 표시.
- 블록: 숫자와 도구를 한 줄로 표시, 손잡이·명령 버튼 드래그로 반복 안팎 이동. 미션 7·8 중첩 반복.
- 미션 4: 반복 순서도, 반복 횟수·마지막 명령 선택 문제, 초록색 확인 결과.
- 교사: 학생의 현재 블록·순서도·명령어 화면만 직접 수정. 학생에게 글 피드백 팝업 전송.
- 심화: 편집 영역의 성공·실패 색상, 실제 최대 점수, 재도전·다음 미션 버튼, 최고 기록 보관.

교사 주소는 인증키 없는 `/teacher`, 학생 주소는 `/student/join`을 유지합니다. 추가 유료 API·서비스를 도입하지 않았습니다. 기존 미니 PC와 Cloudflare 임시 터널을 사용합니다.

기존 실행 창을 종료하고 새 폴더에 압축을 풀어 START.cmd와 TUNNEL.cmd를 실행하세요. 기존 데이터 폴더를 삭제하거나 수업을 초기화할 필요는 없습니다. DB 8→9 변경 전 자동 백업을 수행합니다.

전체 단위 검사 1,288개, 수정 기능 중심의 교사·학생 브라우저 검사, 린트·타입 검사·빌드를 통과했습니다. 드래그 이동·중첩 반복·직접 수정·피드백 팝업·결과 버튼의 화면 내 표시를 확인했습니다. 최종 실행 묶음의 DB 8→9 업그레이드·백업·기존 답안 보존·재시작도 확인했습니다. 검증별 빌드와 범위는 ZIP 안 verification.json에 기록했습니다. 실제 Windows에서 새 ZIP을 실행한 결과와 학교망 접속은 아직 확인 전입니다.

실제 미니 PC에서 새 파일을 실행한 결과, 학교망 접속과 이번 빌드의 30명·90분 부하 검사는 아직 확인하지 않았습니다. 이전 Windows 부하 결과를 이번 버전의 결과로 대체하지 않습니다.
