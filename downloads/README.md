# 알고리즘 탐험 교실 — 반복 학습·효과음·전체 완료 개선판

[Windows ZIP 내려받기](./algorithm-grid-windows-pilot.zip) · [시작 안내](./START-HERE.md) · [SHA256](./algorithm-grid-windows-pilot.zip.sha256)

- 반복 명령 기본 활성화. 기존 수업에도 1회 적용하며 수업 정지·생각시간·실행 잠금은 보존합니다.
- 미션 4의 명령 카드를 선택해 [1·2] [3·4] [5·6] 반복과 마지막 명령을 시각적으로 확인합니다. 다른 풀이는 실제 명령 순서로 판정합니다.
- 성공한 기본 풀이는 보관하고, 반복 만들기는 빈 반복 블록 하나로 시작합니다.
- 실행 버튼 4개를 한 줄로 배치하고 미션 4의 자전거 이동 링크를 제거했습니다.
- 미션 1~4 제출 후 ‘수업 버튼을 눌러 5~8단계에 도전하세요!’ 안내.
- 성공·실패 효과음, 소리 켜기/끄기. 유료 API나 외부 음원 없이 브라우저에서 생성합니다.
- 1~4 제출 + 5~8 성공 시 ‘축하합니다. 알고리즘을 정복했습니다!’ 팝업과 축하 소리. 학생별 확인 기록으로 재접속 시 중복 축하를 막습니다.

교사 `/teacher`, 학생 `/student/join`, 기존 Windows 미니 PC·Cloudflare 임시 터널 방식을 유지합니다. 추가 유료 API·서비스는 없습니다.

기존 START·TUNNEL 창을 종료하고 새 폴더에 압축 해제한 뒤 START.cmd → TUNNEL.cmd를 실행하세요. 업데이트를 위해 데이터 삭제나 수업 초기화를 할 필요가 없습니다. DB 9→10 전 자동 백업 후 새 설정을 적용합니다.

전체 단위 검사 1,298개, 관련 브라우저 시나리오 9개, 린트·타입 검사·최종 빌드를 통과했습니다. 반복 묶음 선택·빈 반복 블록·한 줄 실행 버튼·성공/실패/음소거·전체 완료 축하·재접속 중복 방지를 확인했습니다. 최종 패키지의 백업·9→10 업그레이드·기존 답안 및 수업 잠금 보존·재시작도 확인했습니다. 검증 범위는 ZIP의 verification.json에 기록했습니다.
