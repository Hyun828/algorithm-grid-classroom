# 수업 활동 수정판 · Windows 실행 파일

[ZIP 내려받기](algorithm-grid-windows-pilot.zip) · [처음 실행 안내](START-HERE.md)

추가 유료 API 없이 기존 미니 PC에서 실행합니다. 교사 `/teacher`, 학생 `/student/join` 링크 방식은 그대로입니다.

## 이번 수정

- 자전거 명령을 `빨강, 앞, 2`처럼 간단한 한글로 입력합니다. 상단 중복 ‘명령 고치기’를 없앴습니다.
- 앞으로 칸 수를 블록·순서도·명령어에서 바꿉니다. 중간 장애물과 명령 순서를 확인하면서 이동을 묶을 수 있습니다.
- 다리 미션은 기본 블록 → 겹치는 묶음 찾기 → 반복 블록 → 기본 순서도 → 반복 순서도 → 기본 명령어 → 반복 명령어로 이어집니다.
- 새 학급은 샌드위치 도입 화면에서 기다리며 교사의 ‘미션 시작 허용’ 후 진행합니다. 기존 학급은 업그레이드로 초기화하지 않습니다.
- 교사는 학생 풀이의 사본을 고쳐 실행해 보고 피드백·수정 제안을 보낼 수 있습니다. 학생이 확인하고 적용하며, 이미 바뀐 명령은 덮어쓰지 않습니다.
- 1~4번 제출 후 5~8번 블록 도전이 열립니다. 블록 수가 적을수록 높은 점수이며 최고 기록을 유지합니다.
- 수업 잠시 멈춤·생각시간 버튼은 교사 현황의 접속 옆에 항상 있습니다. 생각시간도 학생 입력을 모두 막고, 지도는 가리지 않는 위쪽 안내를 보여 줍니다.

## 검증 범위

전체 단위 검사 1,277개와 후속 변경 검사, 교사·학생 브라우저의 수정 기능·키 없는 접속·초기화 검사, 린트·타입 검사·빌드를 통과했습니다. 최종 실행 묶음의 DB 7→8 업그레이드·백업·기존 답안 보존·재시작을 확인했습니다. 출시 후보에서는 합성 학생 30명·60초 API 저장·재연결 검사도 통과했습니다. 검증별 빌드와 범위는 ZIP 안 verification.json에 기록했습니다. 실제 Windows에서 새 ZIP을 실행한 결과와 학교망 접속은 아직 확인 전입니다.

이전 버전의 Windows 30명·90분 보고서는 보존합니다. 이번 파일을 실제 Windows·학교망에서 실행한 결과나 이번 버전의 90분 통과로 간주하지 않습니다. 기존 클라우드 90분 실패 이력도 보존합니다.

새 파일은 새 폴더에 풀고 기존 START·TUNNEL을 종료한 뒤 새 폴더에서 실행하세요. 같은 Windows 사용자와 DB 경로를 사용하면 기존 자료를 유지합니다. 데이터와 내부 `.room-key` 파일은 삭제하지 마세요. 사용자가 선택한 공개 교사 접속 방식이 유지됩니다.

ZIP·체크섬·안내 두 파일만 전달 전용 브랜치에 게시합니다. 미니 PC 자동 설치나 기본 브랜치의 앱 배포는 하지 않습니다.
