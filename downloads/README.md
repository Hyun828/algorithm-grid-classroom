# 알고리즘 탐험 교실 — 단계·교사 수정·다시하기 개선판

[Windows ZIP 내려받기](./algorithm-grid-windows-pilot.zip) · [시작 안내](./START-HERE.md) · [SHA256](./algorithm-grid-windows-pilot.zip.sha256)

- 자전거 ‘보라’ 표기와 ‘보라, 앞, 2’ 명령어. 기존 영어 명령어도 읽습니다.
- 오른쪽 단계 설명 중복 제거, 실행 명칭 축약, 현재 위치 테두리와 완료 초록색 표시.
- 교사 수정 후 학생 단계 유지, 추가·변경·삭제 내역 색상과 메시지 안내.
- 순서도 삭제 버튼 제거, 순서도·명령어 성공 시 편집 영역 전체 초록색.
- 현재 미션 처음부터 다시하기: 복구본 보관 후 작성 상태만 초기화. 다른 미션·기존 제출·최고 기록 보존.
- 심화 최대 1,000점, 최소 블록 수 대비 하나 더 쓰면 50점 차감. 성공 기본 100점 보장. 기존 최고 풀이로 새 점수 계산.

교사 `/teacher`, 학생 `/student/join` 주소와 기존 Windows 미니 PC·Cloudflare 임시 터널 방식을 유지합니다. 추가 유료 API·서비스는 없습니다.

기존 START·TUNNEL 창을 종료하고 새 폴더에 압축을 푼 뒤 START.cmd → TUNNEL.cmd를 실행하세요. 기존 데이터 폴더는 삭제하지 마세요. 업데이트를 위해 수업 초기화를 누를 필요는 없습니다.

전체 단위 검사 1,293개와 후속 저장 확인 검사 38개, 관련 브라우저 시나리오 9개, 린트·최종 빌드·타입 검사를 통과했습니다. 교사 이동 지시 후 수정해도 명령어 단계가 유지되는지, 변경 안내·완료 색상·현재 미션 다시하기·다른 미션 및 제출 보존을 확인했습니다. 최종 패키지의 백업·업그레이드·재시작도 확인했습니다. 검증 범위는 ZIP의 verification.json에 기록했습니다.

실제 미니 PC에서 이 ZIP 실행, 학교망과 30명·90분 부하 재시험은 확인 전입니다. 이전 버전의 결과를 새 버전의 실측 결과로 대체하지 않습니다.
