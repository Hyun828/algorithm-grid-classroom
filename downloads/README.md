# Windows 교실 실행 ZIP — 교사 인증키 제거

[새 ZIP 다운로드](./algorithm-grid-windows-pilot.zip?raw=true) · [교체·실행 안내](./START-HERE.md)

현재 교실 기능과 학생 기록 저장 방식을 유지하면서 교사 주소를 `/teacher`로 통일했습니다. 다른 PC의 새 브라우저에서도 인증키 없이 접속합니다. 학생 주소는 `/student/join`입니다. 추가 유료 서비스나 호스팅 변경은 없습니다.

새 ZIP은 별도 폴더에 풀고 기존 START·TUNNEL을 종료한 뒤 새 폴더의 두 파일을 실행하세요. 같은 Windows 사용자·DB 경로를 사용하면 기존 자료를 유지합니다. 내부 `.room-key` 파일은 서버에서 계속 사용하므로 삭제하지 마세요.

사용자가 교사 화면의 공개 접속을 선택했습니다. 교사 주소로 접속한 학생도 답안 조회·수업 제어·초기화를 할 수 있습니다.

이번 변경의 단위 검사 49개, 교사 접속·답안 보존·초기화 브라우저 검사, 린트·타입 검사·빌드, 실행 묶음의 DB 승계·재시작 검사가 통과했습니다. 브라우저 첫 실행은 10개 통과·1개 실패(중복 별칭 오류 뒤 입력칸 포커스)였고, 해당 기존 검사는 분리한 반복 3회에서 통과했습니다. 포커스의 간헐적 실패가 해결됐다고 주장하지 않습니다. 실제 Windows에서 이번 ZIP 실행과 학교망 검사는 아직 하지 않았습니다. 안내 파일은 클라우드 브라우저의 file URL 정책 제한으로 동일 HTML을 로컬 HTTP에서 검사했으며 Windows 파일 열기는 미확인입니다.

이전 버전에 대해 사용자가 제공한 Windows 보고서는 합성 학생 30명·90분 API 부하 검사 통과(계획 밖 실패 0건, 저장 사건 18,125건 일치)를 기록했습니다. 이는 이번 ZIP의 90분 재검사 결과나 학교망·실제 30대 브라우저 검증을 뜻하지 않습니다. 이전 클라우드 90분 성능 실패 기록도 보존합니다.

실제 미니 PC에는 자동 반영하지 않았습니다. ZIP과 안내 4개 파일만 전달용 브랜치에 게시하며 기본 브랜치와 앱 배포 설정은 변경하지 않습니다.
