# 단계·교사 수정·다시하기 개선판 시작하기

1. 새 ZIP을 **새 폴더에 전부 압축 해제**하세요. 이전 폴더는 보관하세요.
2. 기존 START와 TUNNEL 창을 각각 Ctrl+C로 종료하세요.
3. 같은 Windows 사용자로 새 폴더의 **START.cmd**를 실행하세요. 기존에 `--database`나 `--port`를 지정했다면 같은 설정을 사용하세요.
4. 준비가 끝나면 새 폴더의 **TUNNEL.cmd**를 실행하세요. DB 경로를 지정했다면 TUNNEL에도 같은 경로를 지정하세요.
5. 열린 안내의 **다른 컴퓨터에서 접속**에서 교사용 주소를 복사하세요. 이전 안내 탭이 보이면 F5로 갱신하세요.

- 교사: `https://현재터널주소.trycloudflare.com/teacher` — 인증키 입력 없음
- 학생: `https://현재터널주소.trycloudflare.com/student/join` — 번호나 별칭 입력

위 주소는 형태 예시입니다. 안내에 표시된 실제 주소를 사용하세요. `127.0.0.1`은 미니 PC 자체에서만 열립니다.

기존 DB와 서버 내부 식별 파일은 그대로 사용합니다. 기본 저장 위치는 `%LOCALAPPDATA%\AlgorithmGridClassroom`이며 삭제하거나 옮기지 마세요. 이번 교체에 수업 초기화는 필요 없습니다.

터널을 다시 실행하면 주소가 바뀝니다. 새 주소에서 기존 학생의 브라우저 세션은 자동 이전되지 않지만 서버에 저장된 답안은 남습니다. 수업 중 교체하지 말고 교사 화면에서 기존 자료를 확인하세요.

사용자 선택에 따라 교사 주소를 아는 사람은 누구나 교사 화면에 접속할 수 있습니다. 학생에게는 학생용 주소를 전달하세요.

자세한 안내와 검증 범위는 ZIP의 `README-PILOT.md`, `verification.json`을 확인하세요.

새 학급은 도입 화면부터 시작합니다. 교사 현황에서 영상을 보여 준 뒤 **미션 시작 허용**을 누르세요. 이어가는 학급은 업그레이드 후 기존 진도를 유지합니다. 도입부터 새 반 수업을 시작할 때만 ‘다음 학급으로 초기화’를 사용하세요. 초기화는 기존 학급 기록을 삭제합니다.

이번 수정판에서는 오른쪽 학습 단계 목록을 바로 누를 수 있습니다. 미션 4는 반복 순서도와 예시 선택형 문제로 진행하고, 미션 5~8은 블록만 사용합니다. 미션 7·8에서는 반복 안에 반복을 넣을 수 있습니다.

블록 왼쪽 손잡이를 잡아 끌고, 표시되는 ‘여기에 놓기’에 놓으세요. 위쪽 명령 버튼도 끌어서 반복 안에 넣을 수 있습니다. 숫자 입력 칸은 그 자리에서 바꿉니다.

교사는 학생 상세의 ‘현재 풀이’에서 **수정 시작**을 누르세요. 학생이 해당 미션을 열어 두면 마지막 입력을 저장한 뒤 편집이 열립니다. **학생 화면에 저장**을 누르면 바로 반영되며 학생 수락은 필요 없습니다. 학생에게 전할 말은 **피드백 보내기**를 누르면 팝업으로 표시됩니다.

교사 수정 후 학생의 현재 단계는 유지되고, 왼쪽 아래에 추가·변경·삭제 내역이 표시됩니다. ‘확인’을 누르면 닫힙니다.

오른쪽 목록 아래 ‘이 미션 처음부터 다시하기’는 **현재 미션의 작성 중 풀이만** 초기화합니다. 확인창에서 진행하면 먼저 복구본을 보관하고 서버 저장을 확인한 뒤 첫 화면으로 돌아갑니다. 다른 미션, 제출 기록, 최고 점수는 남습니다. 전체 학급 초기화와 다릅니다.

오른쪽 초록색 ✓는 완료, 테두리는 현재 위치입니다. 학습 1·2단계는 다음 단계 버튼으로 완료합니다. 답안을 바꾸면 관련 성공 확인이 해제됩니다.

심화 미션은 최대 1,000점입니다. 성공 기본 100점 + 효율 가산점 최대 900점이며 최소 블록 수보다 하나 늘어날 때마다 50점 차감합니다. 제출한 최고 풀이를 보존하고, 기존 풀이도 새 기준으로 표시합니다.
