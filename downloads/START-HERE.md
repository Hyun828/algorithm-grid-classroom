# 인증키 없이 교사 화면 열기

1. 새 ZIP을 **새 폴더에 전부 압축 해제**하세요. 이전 폴더는 보관하세요.
2. 기존 START와 TUNNEL 창을 각각 Ctrl+C로 종료하세요.
3. 같은 Windows 사용자로 새 폴더의 **START.cmd**를 실행하세요. 기존에 `--database`나 `--port`를 지정했다면 같은 설정을 사용하세요.
4. 준비가 끝나면 새 폴더의 **TUNNEL.cmd**를 실행하세요. DB 경로를 지정했다면 TUNNEL에도 같은 경로를 지정하세요.
5. 열린 안내의 **다른 컴퓨터에서 접속**에서 교사용 주소를 복사하세요. 이전 안내 탭이 보이면 F5로 갱신하세요.

- 교사: `https://현재터널주소.trycloudflare.com/teacher` — 인증키 입력 없음
- 학생: `https://현재터널주소.trycloudflare.com/student/join` — 번호나 별칭 입력

위 주소는 형태 예시입니다. 안내에 표시된 실제 주소를 사용하세요. `127.0.0.1`은 미니 PC 자체에서만 열립니다.

기존 DB와 서버 내부 식별 파일은 그대로 사용합니다. 기본 저장 위치는 `%LOCALAPPDATA%\AlgorithmGridClassroom`이며 삭제하거나 옮기지 마세요. 이번 교체에 수업 초기화는 필요 없습니다.

터널을 다시 실행하면 주소가 바뀝니다. 새 주소에서 기존 학생의 브라우저 세션은 자동 이전되지 않지만 서버에 저장된 답안은 남습니다. 수업 중 교체하지 말고 교사 화면에서 기존 자료를 확인하세요.

사용자 선택에 따라 교사 주소를 아는 사람은 누구나 교사 화면에 접속할 수 있습니다. 학생에게는 학생용 주소를 전달하세요.

자세한 안내와 검증 범위는 ZIP의 `README-PILOT.md`, `verification.json`을 확인하세요.
