# 집 미니 PC 접속 시험

## 합의한 범위

- 개발: Codex 클라우드. 집 PC에서는 클라우드에서 빌드한 앱을 실행한다.
- 운영 후보: 집의 Windows 11, Ryzen 5 PRO 6650H, RAM 16GB 미니 PC. OpenClaw는 외부 AI 서비스를 이용하며 수업 앱과 연결하지 않는다.
- 비용: 추가 유료 API·호스팅·DB·계정 구매 없음. 기존 인터넷과 전력을 이용한다.
- 지금: 가상 학생 3명으로 접속·권한·저장·복구 확인. 실제 학생 정보는 입력하지 않는다.
- 최종: 기능 완성 후 학생 30명과 교사 화면 1개로 90분 시험. 실제 학급 25명에 학생 여유분 5명을 둔다. OpenClaw를 함께 실행하고 실제 집 PC·학교망에서 확인한다.

## 실행 묶음

클라우드의 기존 production 빌드, 공개 정적 파일, 잠금 파일, DB 마이그레이션을 복사한다. 소스 개발 환경과 Linux의 node_modules는 복사하지 않는다. Windows용 Node.js 24를 함께 제공하며 첫 실행 때 npm이 잠금 파일에 따라 Windows 운영 의존성을 설치한다. Windows에서 소스 편집이나 앱 빌드는 하지 않는다.

실제 수업 DB, `.env`, 인증 쿠키, Git 정보는 묶음에 포함하지 않는다. Node와 cloudflared는 공식 다운로드와 공식 SHA-256을 대조하며 라이선스와 검증값을 묶음에 보관한다. 실행 창의 PATH만 바꾸고 시스템 Node·OpenClaw·방화벽·자동 시작·전원 설정은 변경하지 않는다.

1. ZIP을 미니 PC의 짧은 경로(예: `C:\ClassroomPilot`)에 **전부 압축 해제**한다. ZIP 내부에서 바로 실행하지 않는다.
2. `START.cmd`를 실행한다. 첫 실행은 의존성 다운로드가 필요하다. DB 확인과 서버 준비 메시지가 나온 뒤 창을 유지한다. 관리자 실행은 필요 없다.
3. `TUNNEL.cmd`를 별도로 실행한다. 창에 표시되는 `https://…trycloudflare.com` 주소를 브라우저에서 연다. 이 동작은 수업 앱을 임시로 외부 공개한다. OpenClaw 관리 화면은 공개하지 않는다.
4. 같은 주소를 휴대전화의 모바일 데이터 또는 다른 외부 회선에서도 열어 본다. 이것은 학교망 검증을 대신하지 않는다.
5. 아래 시험을 마치면 터널 창에서 Ctrl+C, 앱 창에서 Ctrl+C로 종료한다. 다른 Node·OpenClaw 프로세스를 일괄 종료하지 않는다.

포트 3210이 이미 사용 중이면 다른 프로그램을 종료하지 않는다. 명령 창에서 `START.cmd --port 3212`, 별도 창에서 `TUNNEL.cmd 3212`처럼 같은 빈 포트를 지정한다.

시험 DB는 기본적으로 `%LOCALAPPDATA%\AlgorithmGridClassroom\pilot-data.sqlite`에 보존된다. 재시작해도 삭제하지 않는다. 업데이트 시 압축 해제 폴더와 DB를 구분한다. 실제 운영 전에는 별도의 백업·복구 준비가 필요하다.

## 수정판으로 바꾸기

1. 새 ZIP을 **새 폴더**에 전부 압축 해제한다. 실행 중인 예전 폴더에 덮어쓰지 않는다.
2. 기존 **START 창에서만 Ctrl+C**로 앱을 종료한다. 터널 주소와 참여 권한을 유지하려면 **TUNNEL 창과 브라우저는 그대로 두고 예전 폴더도 보관한다**.
3. 새 폴더의 `START.cmd`를 실행한다. 같은 Windows 사용자로 실행하면 기존 외부 DB를 이어서 사용한다. 기존에 `--database`나 다른 포트를 지정했다면 새 실행에도 같은 값을 사용한다.
4. 기존 HTTPS 주소를 새로고침한다. 터널이 계속 실행 중이면 `TUNNEL.cmd`를 또 실행할 필요가 없다. 터널도 종료했다면 새 폴더에서 다시 실행하고 새 HTTPS 주소를 사용한다.

새 버전이 기존 DB 구조를 갱신해야 할 때는 실행기가 먼저 DB 옆에 백업을 만들고 경로를 표시한다. 백업을 만들지 못하면 갱신과 실행을 중단한다. 새 버전으로 갱신한 DB를 예전 앱으로 열거나 백업 파일을 실행 중 덮어쓰지 않는다. 기본 데이터 폴더나 `-wal`, `-shm` 파일을 삭제할 필요는 없다.

수정판은 교사의 **이 활동으로 모두 이동**, 수업 정지 중 입력 차단, 활동 열기·닫기, 상단 생각 시간을 반영한다. 표현 활동은 **순서도 → 명령어로 쓰기 → 확인·제출**이며, **명령 고치기**로 원래 편집 화면에 돌아갈 수 있다. 자전거 명령은 `("blue", 앞, 1)`처럼 쓰며 이전 `자전거(...)` 형식도 읽는다.

## 짧은 실사용 확인

1. 공개 주소의 교사 화면에서 `접속 시험` 수업을 만들고 학생 참여 코드를 확인한다.
2. 서로 다른 브라우저 프로필 또는 기기 3개에서 `시험1`, `시험2`, `시험3`으로 참여한다. 같은 브라우저의 일반 탭 3개는 쿠키를 공유하므로 독립 학생 시험이 아니다.
3. 각 학생이 서로 다른 경로 계획과 명령을 작성하고 **저장됨** 표시를 확인한다. 교사 화면에서 세 학생과 각 답안이 구분되는지 본다.
4. 학생 화면을 새로고침해 자기 답안이 복원되는지 확인한다.
5. **터널 창과 브라우저는 유지**하고 앱만 Ctrl+C로 종료한 뒤 `START.cmd`로 다시 실행한다. 학생·교사 화면을 새로고침해 답안과 관리 권한이 유지되는지 확인한다.

터널 주소를 바꾸면 기존 주소의 교사·학생 쿠키를 사용할 수 없다. 주소가 바뀐 시험은 새 수업과 새 가상 별칭으로 시작한다. 데이터가 지워졌다는 의미는 아니다. 현재 Quick Tunnel은 장기 고정 주소나 정규 수업 가용성을 보장하는 운영 수단으로 확정하지 않았다.

## 판정과 남은 작업

클라우드의 모의 접속, Windows 실제 실행, 외부 회선 접속, 학교망 접속, 최종 30명·90분 결과를 각각 기록한다. `/api/health` 응답만으로 DB 저장이나 사용자 접근 성공을 판정하지 않는다. Windows PC에 원격 실행 경로는 아직 없으므로 사용자가 실행 결과를 알려 주기 전에는 실제 PC 검증 완료로 표시하지 않는다.

공개 수업의 생성 제한·데이터 삭제 등 남은 보안 작업을 끝내기 전에는 가상 데이터로 감독하에 짧게 시험한다. 실패 시 자동으로 유료 서비스로 전환하지 않고 원인과 필요한 최소 수정만 확인한다.
